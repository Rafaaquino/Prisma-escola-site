6º ano • IA, dados, nuvem e IoT

1. O que chamamos de “nuvem” nesse contexto?

2. Qual sequência representa melhor a jornada de um dado?

3. O que é IoT?

4. Cite um exemplo de dispositivo que pode enviar dados para um sistema de IA.

5. Por que devemos ter cuidado com os dados enviados a serviços de IA?

6. Explique com suas palavras o que acontece com um dado depois que ele é enviado pela Internet para ser processado.

Atividade prática: A jornada de um dado

Você vai escolher um dispositivo diferente do exemplo e acompanhar o caminho de um dado desde o dispositivo até o resultado.

Exemplo do professor: geladeira inteligente
A geladeira possui sensores que identificam a temperatura → envia os dados pela Internet → os dados chegam a um servidor → um sistema analisa a temperatura → o sistema pode avisar que a temperatura está muito alta.

Agora não escolha a geladeira.

7º ano • IA, prompts e segurança digital

1. O que é um prompt?

2. Qual prompt apresenta maior risco?

3. Qual é uma boa regra ao usar IA?

4. Classifique: “Enviar uma foto de um documento pessoal para uma IA.”

5. Reescreva de forma segura: “Crie uma história usando meu nome completo, endereço, telefone e senha.”

6. Explique por que uma senha nunca deve ser colocada em um prompt.

Atividade prática: Prompt seguro ou perigoso?

Leia cada situação. Classifique como SEGURO, CUIDADO ou PERIGOSO e explique sua escolha.

8º ano • IA, dados, padrões e vieses

1. Por que os dados são importantes para sistemas de IA?

2. O que pode acontecer se os dados de treinamento forem incompletos ou pouco variados?

3. O que significa viés em um sistema de IA?

4. Dê um exemplo de sistema de IA que poderia ser afetado pela qualidade dos dados.

5. Imagine uma IA treinada somente com fotos de cães e gatos. Que problema poderia aparecer ao tentar reconhecer outro animal?

6. Complete: “Antes de confiar no resultado de uma IA, devemos perguntar...”

Atividade prática: investigue o sistema

Escolha uma situação. Pense nos dados que a IA usaria, em um possível problema nesses dados e no efeito que isso poderia causar.

9º ano • IA, deepfakes e verificação

1. Um conteúdo criado por IA é automaticamente falso?

2. Qual é o objetivo do protocolo CHECK 5?

3. “Muita gente compartilhou, então é verdade.” Qual é o problema?

4. Para a afirmação “Estudo revela que estudantes que usam IA todos os dias deixam de aprender”, qual seria a primeira coisa a investigar?

5. Por que “não encontrei provas” não significa necessariamente “é falso”?

6. Escreva duas perguntas que você faria antes de compartilhar uma notícia suspeita.
